Create 5–10 sentences based on structures from the current Roman Letter that can realistically be used in the user's own life.

The goal is ACTIVE English. Do not create sentences that sound like ancient Rome unless the structure itself requires it.

Prefer situations such as: work; studying; friends; travel; hobbies; daily life; expressing opinions; explaining something; telling stories.

Also identify which grammar structure each sentence practices.
