# Littera

O Littera é um app de repetição espaçada para ajudar você a aprender inglês no seu ritmo. Estude palavras, expressões e frases com cartões que voltam no momento certo para reforçar sua memória.

Pratique a escrita criando frases próprias, acompanhe seu progresso e ouça a pronúncia em inglês. Você também pode adicionar seus próprios cartões e organizar o vocabulário que quer aprender.
